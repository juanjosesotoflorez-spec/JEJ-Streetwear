## 👕 Sobre el proyecto

**JEJ-STREETWEAR** es un proyecto de desarrollo web orientado a la creación de una tienda virtual de ropa urbana. Su propuesta combina una identidad visual moderna con funcionalidades para la presentación de productos y la gestión de diferentes procesos de una tienda en línea.

La plataforma está inspirada en la cultura streetwear y utiliza una estética basada principalmente en los colores rojo, negro y blanco, buscando transmitir personalidad, estilo y autenticidad.

El proyecto integra tecnologías frontend y backend, junto con una base de datos MySQL, para trabajar en funcionalidades relacionadas con el catálogo, las cuentas de usuario, el carrito de compras y la administración de la tienda.

## ✨ Características principales

### 🛍️ Catálogo y productos
- Presentación de productos de moda urbana.
- Organización y consulta de prendas.
- Búsqueda y filtros de productos.
- Paginación del catálogo.
- Visualización de productos y sus imágenes.

### 🔐 Usuarios y acceso
- Interfaces de registro e inicio de sesión.
- Separación de funcionalidades según el tipo de usuario.
- Acceso a las secciones correspondientes a clientes y administradores.

### 🛒 Carrito y compras
- Carrito de compras.
- Flujo de compra de demostración.
- Organización de las funcionalidades relacionadas con los pedidos.

### ⚙️ Administración
- Panel administrativo.
- Gestión de productos y pedidos.
- Funcionalidades relacionadas con el inventario.
- Organización de recursos de la tienda.

### 🎨 Diseño e interfaz
- Identidad visual inspirada en la moda urbana.
- Diseño basado en una paleta de colores rojo, negro y blanco.
- Uso de Bootstrap y estilos CSS propios.
- Interactividad mediante JavaScript.
- Orientación a una experiencia de navegación intuitiva.

## 🗂️ Organización del proyecto

La estructura de referencia del proyecto se organiza en directorios que separan las interfaces, los recursos visuales, la lógica del servidor y la documentación.

```text
JEJ-STREETWEAR/
│
├── admin/          # Funcionalidades administrativas
├── assets/         # Recursos visuales y frontend
│   ├── css/        # Estilos
│   ├── img/        # Imágenes
│   ├── js/         # JavaScript
│   └── uploads/    # Recursos cargados
├── auth/           # Funcionalidades de autenticación
├── config/         # Configuración de la aplicación
├── database/       # Archivos relacionados con SQL
├── docs/           # Documentación
├── includes/       # Componentes y funciones compartidas
├── pages/          # Secciones de la tienda
├── scripts/        # Scripts auxiliares
├── index.html      # Página principal
├── README.md       # Documentación del repositorio
└── ...
```

*Nota: el árbol es ilustrativo y debe corresponder con los directorios presentes en la versión del repositorio que publiques.*
