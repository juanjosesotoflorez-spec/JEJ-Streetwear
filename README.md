# 👕 JE&J Streetwear

> Plataforma web de comercio electrónico enfocada en la venta y gestión de ropa urbana.

## 📌 Sobre el proyecto

**JE&J Streetwear** es una aplicación web desarrollada para gestionar una tienda virtual de ropa urbana. El sistema integra funcionalidades para la visualización de productos, gestión de usuarios, pedidos y administración de la tienda.

El proyecto cuenta con un **panel administrativo** desde el cual se pueden gestionar diferentes procesos de la plataforma, facilitando la administración de productos, usuarios, pedidos, inventario y otros recursos.

Este proyecto fue desarrollado como parte del proceso de formación en **Análisis y Desarrollo de Software del SENA**.

## ⚙️ Instalación

### 📋 Requisitos

Para ejecutar el proyecto localmente necesitas:

- Windows
- XAMPP
- Apache
- MySQL
- PHP
- Navegador web

### 1. Descargar el proyecto

Clona el repositorio o descarga el proyecto y colócalo dentro de la carpeta `htdocs` de XAMPP:

```text
C:\xampp\htdocs\JEJ-Streetwear
```

### 2. Iniciar XAMPP

Abre el panel de control de XAMPP e inicia:

- Apache
- MySQL

### 3. Configurar la base de datos

El proyecto utiliza una base de datos MySQL llamada:

```text
tienda_jej
```

Si el proyecto contiene un archivo `.sql`, impórtalo utilizando **phpMyAdmin**.

### 4. Ejecutar el proyecto

Con Apache y MySQL activos, abre el navegador y visita:

```text
http://localhost/JEJ-Streetwear/
```
